# FIRST Istanbul Experience

An interactive bilingual event website created for Dar Aldawa’s **FIRST — Steps to Effective Treatment** experience in Istanbul, 15–18 September 2026.

## Live website

https://first-istanbul-experience.azhar90.chatgpt.site

## Highlights

- Full-screen branded opening experience and live countdown
- English and Arabic support
- Interactive calendar-style daily agenda
- Scientific symposium agenda and speaker biographies
- Istanbul city guide with live weather and currency information
- Restaurant cards with ratings, photos, reviews, and map links
- One-tap calendar download, WhatsApp, email, and location actions
- Responsive mobile-first layout and motion effects

## Run locally

Requirements: Node.js 22.13 or later and npm.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is built with React, Vinext, TypeScript, and Cloudflare-compatible tooling.
